# Del 4 – CIA-analys

## Beskrivning
Välj ett av hoten från Del 3. Beskriv hur hotet påverkar konfidentialitet, integritet och tillgänglighet. Dokumentera i
cia-analys.md.

## Konfidentialitet
Ransomware kan påverka konfidentialiteten genom att angripare får tillgång till och stjäl känslig information. Det kan exempelvis vara kunduppgifter, lösenord eller interna dokument. Informationen kan sedan läckas eller säljas vidare.

## Integritet
Ransomware kan påverka integriteten genom att angriparen krypterar, ändrar eller raderar filer. Informationen kan då inte längre garanteras vara korrekt eller oförändrad.

## Tillgänglighet
Ransomware påverkar tillgängligheten genom att kryptera filer och göra system otillgängliga för användarna. Detta kan leda till att verksamheten inte kan komma åt viktig information eller använda sina IT-system.

## Sammanfattning
Ransomware påverkar alla tre delar av CIA-triaden. Konfidentialiteten kan påverkas genom att information stjäls och läcks, integriteten genom att data ändras eller förstörs och tillgängligheten genom att filer och system krypteras och blir otillgängliga.
