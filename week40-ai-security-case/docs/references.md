## Källhantering

Examinationsunderlaget används som källa för vad som faktiskt är känt i caset. Externa källor används för att kontrollera information om CIS Controls och relevanta säkerhetsåtgärder.

Inga externa källor har använts för att lägga till nya fakta om den fiktiva incidenten.
