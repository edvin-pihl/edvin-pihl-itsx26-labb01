# Beskrivning
Välj två cybersäkerhetsroller från instuderingsmaterialet. Beskriv vad rollerna gör, vilka kompetenser som krävs och vilken roll studenten själv tycker verkar mest intressant. Dokumentera i yrkesroller.md.

## Cybersäkerhetsroller

# IT-säkerhetstekniker
Arbetar med att skydda och övervaka organisationens IT-system, exempelvis nätverk, servrar och brandväggar. Rollen kräver kunskaper inom nätverk, operativsystem, säkerhetsverktyg och problemlösning.

# Etisk hackare / Penetration Tester
Testar system och nätverk för att hitta sårbarheter innan riktiga angripare gör det. Rollen kräver kunskaper inom cybersäkerhet, nätverk, Linux och olika säkerhetsverktyg.

# Mest intressant
Jag tycker att etisk hackare verkar mest intressant eftersom man får försöka hitta sårbarheter och tänka som en angripare. Det verkar vara en varierande och teknisk roll.
